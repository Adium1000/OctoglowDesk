# Octoglow Browser Downloads

Extensia trimite către Octoglow Connect numai numărul descărcărilor active și progresul lor cumulat. Numele fișierelor, adresele și istoricul nu părăsesc browserul.

## Instalare în Chrome, Edge, Brave sau Opera

1. Deschide pagina de extensii a browserului (`chrome://extensions`, `edge://extensions` sau echivalentul browserului).
2. Activează **Developer mode / Mod dezvoltator**.
3. Apasă **Load unpacked / Încarcă extensia neîmpachetată**.
4. Selectează acest folder `BrowserExtension` din directorul Octoglow Connect.
5. Lasă Octoglow Connect pornit în timp ce descarci.

Extensia comunică exclusiv cu `127.0.0.1:38742`, adică numai cu acest calculator.
